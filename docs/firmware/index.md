# open-yoto Firmware

A from-scratch, open-source firmware for the Yoto Player (C / ESP-IDF). It
reads NFC cards, plays the matching audio and picture, and provides a local
admin mode for loading your own content.

- [Flash Custom Firmware](flash-custom-firmware.md) — back up, connect, and
  flash a supported Yoto Mini.
- [Post-Flash Setup](post-flash-setup.md) — create the admin card, install the
  web UI, and add local media.
- [How It Works](../open-yoto-firmware.md) — the state machine, NFC playback,
  and the admin web UI.
- [Build Environment](../build-setup.md) — ESP-IDF setup and verified UART
  flashing details.
