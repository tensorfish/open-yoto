# Contributing to Open Yoto

See [Project, support & contributing](docs/project.md#contributing) for the
contribution workflow, build/test commands, hardware evidence, and documentation
checks. [Reporting a bug](docs/project.md#get-help) explains what to include and
what to keep private.

Original project code and documentation use the [MIT License](LICENSE).
Preserve existing third-party notices and read the
[licensing scope](docs/project.md#licensing) before contributing assets or code.
Report vulnerabilities using [SECURITY.md](SECURITY.md), not a public bug report.
