# Repository map

- `README.md` — project scope and top-level tooling.
- `firmware/README.md` — ESP-IDF project layout, builds, and hardware flashing.
- `docs/build-setup.md` — ESP-IDF installation and verified Linux UART flash workflow.

- `docs/ai/` — condensed reverse-engineering reference by subsystem.
- `firmware/` — replacement firmware source and ESP-IDF configuration.
- `tools/` — hardware-control helpers: flash, bootloader, and reset.
- `analysis/` — firmware-dump extraction and reverse-engineering scripts.
